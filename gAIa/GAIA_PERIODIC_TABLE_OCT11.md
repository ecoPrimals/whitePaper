## HOW TO USE THIS TABLE

Mendeleev arranged elements by properties and the arrangement
PREDICTED unknown elements. This table arranges epitopes by
type and the arrangement predicts unknown patterns.

**To sort anything — a paper, a civilization, a system, a
meme, a tool — scan it against this table:**

1. Read the thing
2. Check each group: does this pattern appear?
3. If YES: note the epitope number and the instance
4. If NO: move to the next group
5. If you find a pattern NOT in the table: you found a new
   element. Name it. Number it. Add it.

The table is not complete. The gaps are predictions.

## THE GAPS — Predicted Elements Not Yet Found

Like Mendeleev's empty cells, these are patterns the table
structure PREDICTS but we haven't observed yet:

### Group A gaps (Commons):
- **A?** `commons_without_protocol` — a shared tool that persists
  without a published specification. Does this exist? Or is
  protocol REQUIRED for survival?

### Group B gaps (Capture):
- **B?** `capture_without_institution` — can capture operate
  without formal institutional structure? Informal capture?
  If found, it would expand the theory beyond institutions.

### Group C gaps (Builders):
- **C?** `collective_builds` — every builder we've found is
  an individual. Are there tools built by GROUPS from the
  start, without a single founder? Wikipedia comes closest
  but had Wales/Sanger. Is the individual founder ALWAYS present?

### Group G gaps (Membrane):
- **G?** `membrane_creates_content` — we've seen membranes filter
  and transform. Can a membrane CREATE information that doesn't
  exist on either side? McGurk (#78) suggests yes. More instances?

### Group H gaps (Perception):
- **H?** `cross_species_epitope` — we have mantis shrimp (16D)
  and dog (2D). What about echolocation (bats, dolphins)?
  Electric fields (sharks, platypus)? Magnetoreception (birds)?
  Each is a sensory epitope humans lack entirely.

### Group F gaps (Structural):
- **F?** `the_11th_invariant` — we have 10 structural invariants.
  The world sort across civilizations may reveal invariants
  the modern template doesn't contain. Ancient-only invariants.
